## 再実行

Node.js 18以降、Python 3、Playwright、Chromiumを利用します。アプリ／Nodeテストの追加依存は不要です。

```bash
npm test
npm run serve
# 別ターミナル。必要ならPLAYWRIGHT_MODULEとCHROMIUM_PATHを設定。
node tools/browser-smoke.cjs
node tools/change-notice-smoke.cjs
# SW検証は専用の一時HTTPサーバーを自動起動・終了します。
node tools/sw-update-smoke.cjs
```

環境内のPlaywrightは `PLAYWRIGHT_MODULE=/opt/codex/cua_node/lib/node_modules/playwright` で指定できます。既存サーバーのポートを変える場合、最初の2つのブラウザスクリプトには `BASE_URL` を指定できます。
